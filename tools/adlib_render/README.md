# AdLib conversion helper

`adlib.cpp` is adapted from the ScummVM Kyra AdLib driver for offline conversion of the game's sound data. The code carries its upstream copyright and license notices. See `COPYING`, `COPYING.LGPL` and `COPYRIGHT`.

[ScummVM upstream source](https://github.com/scummvm/scummvm/tree/v2.9.1/engines/kyra/sound)
