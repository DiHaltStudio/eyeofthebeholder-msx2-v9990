El juego se maneja como el original: \textbf{con el rat\'on se hace todo}, y el teclado sirve de atajo para moverse y atacar. Con el rat\'on, el \textbf{bot\'on izquierdo coge y deja} objetos y pulsa botones; el \textbf{bot\'on derecho usa} lo que un personaje lleva en la mano.

\textbf{Notas.} Mantener pulsada una tecla de movimiento repite el paso. El objeto que coges con el rat\'on se convierte en el puntero: lo llevas hasta donde quieras dejarlo (una casilla del inventario, el suelo, otro personaje). En la pantalla de t\'itulo, \key{$\uparrow$} \key{$\downarrow$} eligen y \key{ESPACIO} o \key{RETURN} confirman.
